ruian-autocomplete

Czech address autocomplete straight from the browser — no backend.

Vyberte adresu z nabídky…

Both inputs query the ČÚZK RÚIAN address service directly from the browser (CORS is enabled there, so no proxy is needed). For server-side throttling or caching you can instead point the widget at your own proxy via the endpoint option — for instance the simerda/ruian PHP SuggestHandler.
